✨ How it Works

Everything you need to coordinate relief

Smart Priority Detection

Issues affecting 100+ people with high severity are automatically flagged as urgent — no manual review needed.

Skill + Location Matching

Volunteers are ranked and matched to issues using their skills and geographic proximity using Haversine distance.

Live Issue Map

All reported issues appear on an interactive OpenStreetMap with color-coded markers — urgent issues highlighted in red.

Analytics Dashboard

Visual charts showing breakdown by severity, category, and volunteer skills — powered by Chart.js.
